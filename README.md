## 6기 랭킹·칭찬 카드 공유 (Supabase)

기본은 각자 폰에만 저장된다. 기수 전원이 같은 랭킹과 카드를 보려면:

1. supabase.com → New project (무료) 생성
2. SQL Editor → `supabase.sql` 내용 전체 붙여넣고 Run
3. Project Settings → API 의 **Project URL** 과 **anon public** key를 `config.js`에 넣고 push

앱은 진도가 바뀔 때마다 자기 행을 upsert하고, 6기 탭에서 XP 순으로 읽는다. 칭찬 카드는 받는 사람 이름 기준으로 도착한다.
친구 그룹용이라 행 보호는 느슨하다(누구나 갱신 가능). 로그인 자체는 여전히 기기별이며, 폰을 바꾸면 레벨 탭 "데이터 옮기기"로 옮긴다.

## 서버 계정 (어느 폰에서든 로그인)

`supabase-accounts.sql`을 SQL Editor에서 실행하면 계정이 서버(bcrypt)로 가고, 앱은 자동으로 서버 계정을 쓴다.
실행 전엔 기기별 로컬 계정으로 동작. 전체 리셋은 그 파일 맨 아래 주석의 `delete from …` 한 줄.

## 파도 별점 · 체크인 · 파티 모집 (3차)

## 용어 정확도 관리 (학교 기준 맞추기)
앱의 핵심 표현은 `lex.js`(`window.LEX_SEED`) 한 곳에 모아두고, 각 항목에 **출처**(강의노트 / 단톡 코칭 날짜 / 일반 용어 / 앱 제안)를 단다.
index.html과 terms.html이 같은 파일을 읽으므로 표현을 한 곳에서만 고치면 된다.

`supabase-terms.sql` 실행 후 **`terms.html`(용어 검수)** 에서 코치가 표현·설명을 고쳐 저장하면
**앱 전체가 즉시 그 표현으로 바뀐다**(판정·바람·스웰·물때·동작). 멤버는 "고쳐주세요"로 신고 → 코치 큐(status=fix).
앱 안(성장 탭)에는 현황과 바로가기만 둔다 — 편집 UI를 앱에 두면 파도만 보러 온 사람에게도 계속 보인다.

## 캐릭터 (24×24 도트)
머리 12줄 / 몸 8줄 / 보드 4줄의 치비 비율. 구분값은 **실루엣**이다 —
머리 모양 8종 · 상의 5종(래시가드·후디·민소매·풀슈트·맨몸) · 모자 5종 · 보드 3종,
여기에 머리 색 8 · 피부 4 · 표정 5 · 색상들이 얹힌다.

아직 안 꾸민 사람은 **이름 해시**로 기본 모습이 흩어진다(`withLook`). 같은 이름은 어느 기기에서든 같은 모습.

**반려동물** 5종(토끼·고양이·강아지·물개·펭귄)은 제 부기보드를 타고 옆에서 따라온다.
24칸 안에 넣으면 덩어리로만 보여서, 펫이 있으면 장면이 왼쪽으로 12칸 넓어지고 `paint`가 높이 기준으로
캔버스 폭을 다시 준다. 40px 안팎으로 작게 그리는 자리(헤더·채팅)는 `avatarRows(pr, false)`로 펫을 뺀다.

친밀도는 출석·세션 기록·성공한 파도를 따라 저절로 오른다(먹이 주기 버튼 없음).
25/55/90에서 볼터치 → 리본 → 선글라스가 붙고, 단계(`profile.petLv`)는 마을에도 보인다.
