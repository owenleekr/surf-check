SurfShare 가이드

양서학 서퍼들의 앱 — 맛집·서핑 스팟, 차·숙소, 번개, 게임과 훈련. 로그인 없이 누구나 이 페이지를 볼 수 있어요.

🍜 맛집 · 🏄 서핑 스팟 등록하는 법

네이버지도 ‘양서학’ 리스트는 운영자만 고칠 수 있어요. 그래서 누구나 앱에서 등록하면 바로 목록에 올라가고, 운영자가 네이버 리스트에도 넣으면 양서학 리스트 ❌ → 양서학 리스트 ⭕ 로 바뀌어요.

  1. 네이버지도 앱에서 가게를 검색해 장소 화면을 열어요 (지점이 여러 개면 가 본 지점으로)
  2. 장소 화면의 공유 → 링크 복사
  3. SurfShare 앱 → 아래 🍜 맛집 탭 → ➕ 맛집 등록하기
  4. 링크 붙여넣기 · 이름 · 지역 · 한줄평을 적고 등록하기 — 끝! 목록에 바로 떠요(🙋 내 이름·기수 표시)
한줄평 팁 — 첫머리에 핵심, 뒤에 가격·웨이팅. 예: 갈비탕 · 웨이팅 30분 · 점심 전에 가요
‘[네이버지도] 가게이름 … https://naver.me/…’ 를 통째로 붙여도 링크만 알아서 뽑아요.
  1. 네이버지도 앱에서 해변·포인트 이름을 검색해요 (예: ‘물치해수욕장’)
  2. 장소 화면의 공유 → 링크 복사
  3. SurfShare 앱 → 🍜 맛집 탭 → 위의 🏄 서핑 스팟 → ➕ 스팟 등록하기
  4. 링크 · 이름 · 지역 · 한줄 설명 → 등록하기. 앱의 라이브캠 해변과 이름이 같으면 📹 캠 버튼이 붙어요
설명 팁 — 파도 방향·포인트 위치·위험(리프·이안류)·주차. 예: 북쪽 막혀서 큰 파도 좋음 · 주차는 해변 앞 · 초보는 안쪽
⚠️ 군사시설 주변·허가가 필요한 곳은 공개 앱이라 올리지 말아 주세요.

📲 홈 화면에 추가 (앱처럼 쓰기)

한 번 해 두면 카톡에서 링크를 찾지 않아도 아이콘 하나로 열려요. 로그인도 그대로예요.

  1. 사파리로 SurfShare를 열어요
  2. 화면 아래 가운데 공유(□↑)
  3. 목록을 내려 홈 화면에 추가 → 오른쪽 위 추가
iOS 16.4 이상은 크롬에서도 공유 → 홈 화면에 추가가 돼요.
  1. 크롬으로 SurfShare를 열어요 — 앱 홈에 📲 홈 화면에 SurfShare 추가 버튼이 보이면 눌러요
  2. 버튼이 없으면 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치
  3. 삼성 인터넷은 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면
  1. 카카오톡 안 브라우저에서는 홈 화면 추가가 안 돼요
  2. 오른쪽 아래(아이폰) / 위(안드로이드) ⋯ 또는 ⋮ → 다른 브라우저로 열기
  3. 사파리·크롬에서 위 방법대로 추가

💬 댓글 · 👍 추천 · 🙋 가봤어요

맛집·스팟 카드마다 👍 추천, 🙋 가봤어요, 💬 댓글이 있어요. 댓글에는 이름 옆에 기수(6기·서퍼)가 같이 보이고, 댓글마다 ❤️ 공감 · 👍 추천 · ↩ 답글을 달 수 있어요. 내가 쓴 글은 🗑 로 지울 수 있어요.

새 맛집·댓글·게임 기록은 앱 맨 위 📣 소식줄에 돌아가며 떠요 — 누르면 그곳으로 가요.

🛠 운영자용 — 네이버 리스트에 반영하기

  1. 운영자 계정으로 맛집(또는 스팟) 화면을 열면 위에 📥 양서학 리스트 반영 대기 N곳이 보여요
  2. ❌ 카드의 📌 네이버에 넣기 → 네이버지도에서 그 장소가 열려요
  3. ⭐ 저장 → ‘양서학 추천 맛집’(스팟은 ‘양서학 서핑 스팟 리스트’) 선택. 메모에 한줄평을 옮겨 적으면 좋아요
  4. 10분 안에 앱에서 ⭕ 로 바뀌고 네이버 카드 하나로 합쳐져요(댓글·추천은 그대로)
메모에 ‘외부유출 금지’라고 적은 장소는 앱에 올라오지 않아요.

🎮 게임 · 🛹 훈련

🏄 파도 점프 — 메인 게임
🙂 쉬움 / 🔥 어려움 모드(기록 따로). 목숨 3개 · 스테이지 5개(아침 낙산 → 한낮 죽도 → 노을 인구 → 밤 폭풍 → 전설의 파도). 🐦 갈매기는 뛰지 말고, 🪵 통나무는 높이. 아이템 ⭐무적 🧲자석 🐢느리게 ✖️2 💎 🛟 ❤️. 📅 오늘의 챌린지는 모두 같은 코스.
🌊 라인업 서핑
파도 5개 · 목숨 3개. ① 파도가 오면 연타로 패들 ② 바늘이 초록일 때 탭 = 팝업 ③ 누르고 있으면 위로, 떼면 아래로 — 내려가면 빨라져요. 컬 가까이 높이 붙으면 🌀 튜브, 립을 치면 탑턴, 빠르게 치고 오르면 🚀 에어. 앞이 한꺼번에 무너지면(⚠) 빨리 지나가거나 🛑 풀아웃.
🛹 서프스케이트 훈련
땅에서 서핑 동작을 반복하는 연습장. 노란 칸에서 꾹(웅크리기), 벗어나면 떼기(펴기) — 펌핑 · 바텀턴→탑턴 · 컷백 · 플로우 4개 드릴. 끝나면 실제로 해 볼 코칭과 ‘오늘 실제로 탔어요’ 기록.
서프스케이트 드릴 구성 참고: Rapture Camps 「Surfskate Drills for Surfers」 등. 실제 연습은 보호대를 하고 차 없는 곳에서.

❓ 자주 묻는 것

등록하려는데 “이미 있어요”가 떠요
같은 장소가 목록에 있어요. 그 카드에 💬 댓글로 남겨 주세요.
잘못 올렸어요
내 등록 카드의 🗑 로 지울 수 있어요(⭕ 가 되기 전까지).
⭕ 로 안 바뀌어요
운영자가 아직 네이버 리스트에 안 넣은 거예요. 넣고 나서 10분쯤 걸려요.
링크는 어떤 걸 넣어요?
네이버지도 링크만 받아요(naver.me · map.naver.com). 다른 사이트 링크는 안 돼요.

앱을 완전히 껐다 켜거나, 홈 화면 아이콘으로 다시 열어 주세요.
